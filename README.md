# 🎬 MovieCity

Landing Page de filmes desenvolvida com React e Vite para a atividade de Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O MovieCity é uma página web criada para apresentar filmes de diferentes gêneros em uma interface moderna e responsiva. O projeto tem como objetivo praticar os fundamentos do React, a criação de componentes, a utilização de imagens e a estilização com CSS.

## 🚀 Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
- Lucide React

## ✨ Funcionalidades

- Página inicial com banner de destaque.
- Catálogo de filmes com pôsteres, avaliações e gêneros.
- Pesquisa de filmes por título ou gênero.
- Filtros por categoria.
- Menu de navegação responsivo.
- Layout adaptado para computadores, tablets e celulares.
- Rodapé com informações do projeto.

## ⚙️ Como executar o projeto

**1.** Instale o Node.js em seu computador.

**2.** Abra o terminal na pasta do projeto.

**3.** Instale as dependências:

```bash
npm install
```

**4.** Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

**5.** Acesse o endereço indicado no terminal, normalmente `http://localhost:5173`.

## 🧪 Testes

- Verificar se o projeto inicia corretamente.
- Testar a pesquisa de filmes.
- Testar os filtros por categoria.
- Verificar a responsividade em diferentes tamanhos de tela.
- Confirmar se as imagens são carregadas corretamente.

Para verificar a compilação do projeto, execute:

```bash
npm run build
```

## 🎯 Objetivo educacional

Praticar a criação de aplicações com React, a organização de componentes, a importação de imagens, o uso de estados e a construção de interfaces responsivas.
